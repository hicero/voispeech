# VoiSpeech 홈페이지 수정본

## 확인하기
- preview.html: 설치 없이 열 수 있는 HTML 미리보기입니다. 빌드 결과의 스타일을 포함하고 메뉴·FAQ·복사 동작을 연결했습니다.
- app/ 및 components/: 수정된 Next.js 원본 소스.
- out/: 정적 호스팅용 빌드 결과. HTTP 서버로 제공합니다.

## 실행
기존 package.json과 bun.lock을 유지했습니다.
`bun install` 후 `bun run dev`로 개발 서버를 실행합니다.
일반 빌드: `bun run build` 후 `bun run start`.
정적 내보내기: `VOISPEECH_STATIC_EXPORT=1 bun run build`.
검증 환경에서는 Bun 실행 파일이 없어 npm으로 동일 의존성을 설치했습니다.

## 주요 수정
- 네이비·스카이 색감 유지, 첫 화면의 표지형 영역과 핵심 문구 강조.
- 모바일 본문 크기·줄바꿈·버튼·섹션 간격 조정.
- 5 VOICE CHECK 임의 점수 막대를 관찰 질문으로 교체.
- 관찰 → 가능한 연결 → 조절 시도 → 노래 적용으로 코칭 설명 정리.
- 확인되지 않은 후기·18년 경력·예시 가격·임시 연락처·빈 SNS 링크 제거.
- 리포트 작성 예시 명시, 원데이 리포트 제공 일정 별도 안내.
- 전송 없는 신청 성공 표시를 문의 작성·복사 기능으로 교체.
- 메뉴 Escape 닫기, 화면 확대 시 스크롤 잠금 해제, FAQ 접근성, 동작 줄이기 지원.

## 실제 운영 전 확인
components/siteConfig.ts의 contactUrl에 공식 상담 URL을 입력하면 상담 버튼이 나타납니다. 현재 실제 문의 전송 기능은 없습니다.
실제 수업료·정확한 주소·연락처·경력·게재 동의를 받은 후기와 사진은 확인 후 추가하세요.
수업 소개 문구는 운영자 검토용 제안입니다. 실제 수업 구성과 원데이 리포트 제공 범위를 확인하세요.

## 검증
Next.js 정적 프로덕션 빌드, TypeScript, ESLint 통과. HTML 내부 링크와 미리보기 JavaScript 구문 확인.
실기기·브라우저 화면과 상호작용 검증은 수행하지 않았습니다.
